# Lift Log

Personal workout, body-weight and nutrition tracker. Installable web app (PWA), iPhone first.
Vite + React + TypeScript + Tailwind, Supabase (Postgres + Auth + RLS), hosted on Cloudflare Pages. All free tiers.

- Setup and deployment: [docs/SETUP.md](docs/SETUP.md)
- Spec, decisions, data model and task list: [CLAUDE.md](CLAUDE.md)

Not medical advice.
